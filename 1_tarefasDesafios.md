# Lembramed - Desenvolvimento de um Sistema para Lembretes e Gerenciamento de Medicações

- **Título:** Lembramed - Desenvolvimento de um Sistema para Lembretes e Gerenciamento de Medicações
- **Ano:** 2024
- **Autor:** Guilherme da Silva Kuhn
- **Curso:** Ciência da Computação
- **Orientadora:** Ana Paula Canal

## Resumo

Este trabalho apresenta o desenvolvimento de um sistema web utilizando **TypeScript** e o framework **React** no frontend, além de **Node.js** com **Express** no backend. Para o envio de notificações por SMS foi utilizada a API da **Twilio**, enquanto o **MongoDB** foi empregado para o armazenamento de dados.

O desenvolvimento seguiu as boas práticas da metodologia ágil **Feature-Driven Development (FDD)**. Como resultado, foi entregue um sistema capaz de lembrar os usuários de consumir seus medicamentos corretamente, por meio da visualização das medicações programadas para o dia e do envio de mensagens SMS nos horários definidos. Além disso, o sistema permite o gerenciamento de um catálogo de medicamentos, podendo ser utilizado tanto para o cuidado próprio quanto para o acompanhamento da medicação de outras pessoas ou animais.

**Palavras-chave:** React; Medicações; Saúde Digital; Desenvolvimento Web.

## Classificação da rotina da saúde

 **Diagnóstico**: Não, O sistema não identifica doenças nem realiza diagnóstico clínico.
 
 **Monitoramento** Sim (principal) O sistema acompanha o uso dos medicamentos, registra o histórico de utilização, exibe as medicações do dia e envia lembretes por SMS para promover a adesão ao tratamento. 
 
 **Recomendação** Parcialmente O sistema lembra o usuário de tomar medicamentos prescritos e alerta sobre medicamentos vencidos, mas não recomenda novos tratamentos ou medicamentos. 
 
 **Predição / Previsão**  Não O sistema não utiliza inteligência artificial, aprendizado de máquina ou modelos preditivos para prever doenças, riscos ou eventos futuros.
